# Arduino Code

The full Arduino sketches are not included yet. The original files are referenced in the project write-up under these names:

| File | Description |
|---|---|
| `radar_project.ino` | Radar-style OLED display and buzzer sound system (original sketch) |
| `final_code_missile_Launcher_22.ino` | Turret and firing mechanism (adapted from the referenced Instructables project) |
| *(combined sketch)* | Integrated radar, sound, and firing sketch |

Add the `.ino` files here when available. Each Arduino sketch normally lives in a folder with the same name as the file, for example `radar_project/radar_project.ino`.

Partial code excerpts from the project write-up are in [`../docs/code-excerpts.md`](../docs/code-excerpts.md). They are excerpts only and will not compile on their own.

**Libraries needed:** `Servo`, `U8g2`, `Wire`.
